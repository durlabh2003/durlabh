Sample PRD Excerpt: Kartify (Conversational Shopping AI)

Kartify · Core Search & Comparison Matrix (v1.2 MVP)

Owner: Durlabh Daryani | Status: Delivered / Pilot Usability Tested

### 1. Objective & JTBD - **JTBD:** When I am researching high-consideration electronics, I want to compare options based on my specific budget and usage constraints, so I can buy with confidence without opening 20 tabs. - **North Star Metric:** Task Completion Rate (identifying a purchase-ready item within 8 conversational turns). ### 2. Functional Scope - **Must Have:** * Intent parser extracting: Product category, Budget range, 2 core attributes (e.g., battery life, weight). * Structured JSON schema output enforcing side-by-side comparison tables. * Explicit reasoning summary (Why Option A wins over Option B for this user). - **Out of Scope (v1 MVP):** * In-chat checkout / payment processing (external affiliate redirection only). * Voice input and multimodal image uploads. ### 3. AI Workflow & Guardrails - **Prompt Architecture:** 2-stage pipeline (Stage 1: Intent & Attribute Extraction -> Stage 2: Synthesis & Matrix Generator). - **Deterministic Guardrails:** Strict JSON schema validation; automatic retry on invalid schema with temperature 0.1. - **Latency Target:** p90 response latency < 2.8s. ### 4. Acceptance Criteria (QA Gating) - **AC-01:** Given a vague user query ("recommend a laptop"), the system must prompt with at most 2 clarifying options before generating recommendations. - **AC-02:** Comparison tables must cite at least 3 verifiable product specifications per candidate item.
